To decouple task logic from execution backends across heterogeneous agent harnesses, models, and environments, **ageval** (agent eval) combines programmable task scripts with declarative plugin composition. Author a dataset once, and swap the execution environment, harness, and model in configuration.

Equip your local coding agent with the CLI and skills so it can design, convert, and run benchmarks end to end. Publish datasets, plugins, Agent packages, and evaluation results to the Hub so others can inspect and reproduce them.

- **Swap the evaluated agent and environment.** Environments and agent executors connect through declarative plugin slots ([ACP](https://agentclientprotocol.com) by default; `nooa`, `dsh`, `miniswe`, and `openhands` use the same plugin mechanism). Update one line in `profiles.yaml`, or pass `--agent` (and optional `--model`) for a single run.
- **Automate benchmark conversion and execution.** Skills teach your coding agent the CLI, dataset layout, and SDK contracts so it can author or convert a benchmark and execute the evaluation end to end.
- **Share and compare on the Hub.** Run published datasets directly with `ageval run <org>/<name>@<version>`, inspect trajectories, and compare models and harnesses on the Leaderboard.

The CLI command is `ageval` (PyPI package `ageval-cli`).
