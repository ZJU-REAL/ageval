Hub（`apps/hub`）是连 Registry 的网页端，用来浏览共享的包与跑次结果。

- Dataset 列表（你的组织 / 探索）、README、Task 文件预览  
- 包内有根 `shared/` 时：Dataset **Shared** tab；Task **Files** 顶栏 **Local | Shared**（默认 Local；Attempt 证据页不切换）  
- profiles 声明了 `overlays:` 时：Dataset **Overlays** tab；Task **Files** 增加 Overlays 范围；Leaderboard **profiles** 展开可显示 Job 树（Dataset 包）和/或 Agent 树（`agent_ref` 包）。只有一源时不显示另一个 tab；都没有则不显示文件树。不是 suite archive。  
- 大文件预览：超过 Registry 上限时返回截断头并标注 truncated（非整文件下载）  
- **组织**：可在列表页创建或用邀请码加入；成员、组织内的 Dataset / 插件 / Agent（分表）、别人分享过来的 suite 结果  
- **组织设置**：邀请码（创建后只展示一次）；owner 可按 GitHub login 加人、改角色、移除或转让；离开或解散组织  
- Task 下的 **Jobs**：已上传运行产物时可点进详情（界面与本机 Viewer 相近，含轨迹）  
- Dataset 版本切换：有权限的人能看到 **draft (current)**，其他人只能切已发布 release。org owner 可改当前版本可见性、删除该版本，或把 draft 发布成 release  
- Tasks 表：README 是否存在、近期 job 数、最近一次分数/状态  
- Leaderboard：**Public**（默认）只列完备且绑定 release 的 suite；**Internal** 用同一张表列出当前可见的缺题 / draft 绑定跑次。可点表头排序；观测指标，非 suite PASS。展开行有 **profiles** / **plugin** 页签（无密钥 YAML 与再跑命令；插件进 marketplace）。上传者可在 **share** 页签改可见性、分享给 org/user、或删除。Task Jobs 不变。  
- 插件 / Agent 市场用 **卡片**（说明、标签、同一行的累计下载量与收藏量）；Dataset、Jobs、成员、suite 仍是细线表  
- 插件详情：独占 / 链 **声明槽**时间线，点开跳到包内文件预览；浏览器不执行插件  
- 官方组织、这些组织的成员、以及这些组织上的插件显示已验证对勾  
- 公开用户页：身份、GitHub 链（由 login 推导）、可选 bio（本人 PATCH `description`）。组织可有 `description`。不列出私有成员关系  
- 插件 / Agent 卡片与详情同一行展示下载量与 star 数。下载量在成功拉包 content 时加一；star 是登录用户对 plugin / agent 的每人一条记录，操作只在详情页头右侧。Dataset 表不展示这两项。列表 tab 绑查询参数：默认组织（`orgs=1`）、Explore 为 `?visibility=public`、Stars 为 `?favorited=1`（仅 plugin / agent）。组织详情 `?tab=settings`  
- 组织、Dataset、插件、Agent 的 owner 可改展示名（组织标题，或 `org/` 后面的叶子）。存储的包 id 前缀不变  
- 登录后的 **Home**：你上传的 Jobs、组织、可维护 Dataset / Task、你上传的插件与 Agent（标记与标题同 marketplace）。未登录会去登录页。无 publish / upload / release 按钮  
- 列表搜索与 scope tab 同一组；文件树分栏高度固定；轨迹按密封文件顺序展示、tool-call 可折叠；步骤头只在密封行带 `elapsed_ms` 时显示耗时  

- Agent 详情：已发布包（binding + 文件，含 bundled `overlays/`），加上用 `agent_ref` 点名该 Agent 的官方公开 suite 出场。只用 `--profiles` 的 suite 留在 Dataset Leaderboard。

- **用 GitHub 登录**（浏览器 OAuth；CLI 仍是 Device Flow）

## 本地开发

```bash
# 终端 A — 先起 Registry（需配置 OAuth）
export VITE_REGISTRY_PROXY_TARGET=http://127.0.0.1:8700
uv run --extra registry python -m services.registry.app --host 127.0.0.1 --port 8700

# 终端 B
cd apps/hub
pnpm install
pnpm dev   # http://127.0.0.1:5174
```

也可用 `docker compose -f services/registry/docker-compose.yml up -d` 一次起 Hub（`http://127.0.0.1:8080`）与 Registry。发版镜像在 GHCR：`ghcr.io/zju-real/ageval-hub`、`ageval-registry`。

| 路径 | 页面 |
| --- | --- |
| `/home` | 个人主页（需登录） |
| `/datasets` | 列表（Your organizations / Explore） |
| `/datasets/:id` | README · Tasks · Shared（有 shared/ 时）· Overlays（声明了 `overlays:` 时）· Leaderboard |
| `/datasets/:id/tasks/:task` | README · Files（Local \| Shared \| Overlays）· Jobs |
| `/plugins` | 插件 marketplace |
| `/plugins/:id` | 插件详情（声明槽时间线 · 文件预览 · CLI 安装命令） |
| `/agents` | 已发布 Agent 目录 |
| `/agents/:id` | 绑定、文件、按 version 分组的出场 |
| `/organizations` | 我的组织 · 创建 / 加入 · Dataset / 插件 / Agent 计数 |
| `/organizations/:orgId` | 概览（成员 · Dataset · 插件 · Agent）· 设置 |
| `/users/:login` | 公开用户页（官方组织与公开 Dataset / 插件 / Agent；未登录可看） |
| `/datasets/:id/tasks/:task/attempts/:runId` | 远程 Attempt 详情（需已上传对应运行产物） |

登录：点 **Sign in with GitHub** 即可。命令与部署细节见 `apps/hub/README.md`、`services/registry/README.md`。

## 和 Viewer 的区别

| | Viewer | Hub |
| --- | --- | --- |
| 数据 | 本机 `.ageval/suite-runs/` | Registry |
| 入口 | `ageval view` | 浏览器打开 Hub |
| Jobs 产物 | 本地 run 目录 | 需先上传到 Registry |

Jobs 列表里，已有运行产物的行可以点进去看；没上传的会显示 **Not uploaded**，不会编造轨迹。

## 上传什么才能在 Hub 上看到

| 你想看 | 需要上传 | 怎么跑 / 传 |
| --- | --- | --- |
| Dataset **Public Leaderboard** 一行 | **完备**且绑定 **release** 的 suite | 先 `ageval publish --draft` 再 `ageval release`（或直接 `ageval publish`）→ 省略 `--task` 的 `ageval run` → `upload-suite --suite-run <id>` |
| Leaderboard **Internal** | 当前可见的缺题或 draft 绑定 suite | 同样 `upload-suite`；不会出现在 Public |
| Task **Jobs** 可点开 Attempt / 轨迹 | suite + **attempt 证据** | `upload-suite --with-attempts`（或等价挂上 task_refs 的 attempt）；缺题 / draft 绑定也出现在这里 |
| 给已上传 suite 换一格 finished 槽 | 新 Attempt + suite 现行指针 | 本机 `--resume-suite --replace-slot`，再 `upload-suite --suite-run <id> --task <id> [--run <run_id>]`。Hub / Viewer 默认现行；版本列表是 `patch N` + 该 Attempt 开始时间 |
| 只归档一次 Attempt | `ageval results upload --run <run_id>` | 可以进 Registry，但 **通常不会**出现在 Leaderboard |

```bash
# 正确：整包 suite → 上榜
uv run ageval run <dataset> --profiles <profiles.yaml>
uv run ageval results upload-suite <dataset> --suite-run <8-hex> --public --with-attempts

# 不够：单题 attempt upload 单独上传 → 榜上经常空白
# uv run ageval run <dataset> --task <id>
# uv run ageval results upload <dataset> --run <run_id>
```

Hub 前端必须指向与 `ageval login` / `~/.ageval/credentials` **同一** Registry（本机开发常见 `127.0.0.1:8700`）。详见 [运行 Suite](/docs/run/suite)。
