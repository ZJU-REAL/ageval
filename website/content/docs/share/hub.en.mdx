Hub (`apps/hub`) is the web UI on top of Registry: browse shared datasets, plugins, agents, and run results. Sign in with **Sign in with GitHub** in the browser; the CLI stays on Device Flow.

## Local dev

```bash
# Terminal A — Registry first (OAuth configured)
export VITE_REGISTRY_PROXY_TARGET=http://127.0.0.1:8700
uv run --extra registry python -m services.registry.app --host 127.0.0.1 --port 8700

# Terminal B
cd apps/hub
pnpm install
pnpm dev   # http://127.0.0.1:5174
```

Or `docker compose -f services/registry/docker-compose.yml up -d` for Hub at `http://127.0.0.1:8080` plus Registry. Release images live on GHCR: `ghcr.io/zju-real/ageval-hub` and `ageval-registry`.

## Datasets and tasks

- The list is grouped by organization: the group head shows the org name and description; rows carry name, description, task count, and last update. Open one for its README and task file previews.
- Version switching: entitled users see **draft (current)**; everyone else switches among published releases. An org owner can publish the draft, change visibility, or delete a version.
- When the package declares root `shared/` or `overlays:`, the task **Files** header gains **Shared** / **Overlays** scopes (Local by default).
- **Jobs** under a task list uploaded runs; click through for trajectories (the layout is close to the local Viewer).

## Leaderboard

- **Public** lists only suites that are complete, bound to a release, and approved for listing by the dataset org's owner; **Internal** shows caller-visible incomplete or draft-bound runs in the same table.
- The same tab switches **Table** / **Pareto** / **Waffle**. Pareto’s x-axis is the **sum of every job** in the suite (cost, tokens, or time). When the agent did not report USD, cost is tokens × catalog price — estimated, not a billed invoice.
- Metrics are observational summaries, not a suite PASS; headers sort.
- Click a row for the suite run page: **Profiles** / **Plugin** / **Jobs**, with secret-free YAML and rerun commands. Uploaders get Share, Delete, and Attach — link a published model / agent for provenance.
- Listing and Performance requests are batch-approved by org owners in the **Inbox**.

## Plugins, agents, and models

- The plugin / agent marketplace uses cards: description, tags, downloads, and stars. Detail pages show the declared extension-point timeline, file preview, and the CLI install command.
- Agent details add bindings, files, and Performance.
- **Models** in the sidebar is a catalog grouped by lab (context, price, and more; searchable; a row opens its encyclopedia page). Prices are list prices — not bills, not PASS.
- Official orgs, their members, and their plugins carry a verified badge.

## Orgs and sharing

- Create an org or join by invite code; the code is shown in full only once, at creation.
- Owners / admins manage members and roles by GitHub login and can transfer the org; members can `publish` under it.
- Private results can be shared with an org or user; the signed-in **Home** collects your uploaded jobs, packages, plugins, and agents.

## vs Viewer

| | Viewer | Hub |
| --- | --- | --- |
| Data | Local `.ageval/suite-runs/` | Registry |
| Entry | `ageval view` | Browser SPA |
| Job artifacts | Local run dirs | Must be uploaded first |

Jobs rows with uploaded run artifacts open detail; others show **Not uploaded**. Trajectories are never invented.

## What to upload so Hub shows it

| You want | Upload | How |
| --- | --- | --- |
| A **Public Leaderboard** row | A **complete**, **release-bound** suite **listed** by the Dataset org owner | `ageval publish --draft` then `ageval release` (or a direct `ageval publish`) → `ageval run <dataset>` **without** `--task` → `upload-suite --suite-run <id>` → `ageval results request --kind leaderboard_list --suite-run <id>` (owner approves in Hub Inbox) |
| Leaderboard **Internal** | A caller-visible incomplete or draft-bound suite | Same `upload-suite`; does not appear on Public |
| Task **Jobs** with openable Attempt / trajectory | Suite + **attempt** evidence | `upload-suite --with-attempts`; incomplete / draft-bound suites stay here |
| Patch one finished slot on an uploaded suite | New Attempt + suite slot pointer | Local `--resume-suite --replace-slot`, then `upload-suite --suite-run <id> --task <id> [--run <run_id>]`. Hub/Viewer default to current; the version list is `patch N` plus that Attempt’s start time |
| Archive one Attempt only | `ageval results upload --run <run_id>` | May exist in Registry, but **usually not** on Leaderboard |

```bash
# Correct path for Leaderboard
ageval run <dataset> --profiles <profiles.yaml>
ageval results upload-suite <dataset|id@version> --suite-run <8-hex> --public --with-attempts

# Not enough for Leaderboard: single-task attempt upload alone
# ageval run <dataset> --task <id>
# ageval results upload <dataset> --run <run_id>
```

Dataset Leaderboard lists every suite that passed the board gate. The header version switcher only changes README / Tasks. The Select to the right of Public filters rows by the suite's `dataset_version` (default All versions).

Point Hub at the **same** Registry as `ageval login` / `~/.ageval/credentials` (local dev often `127.0.0.1:8700`).
