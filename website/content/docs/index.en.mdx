How do you avoid rewriting scaffolds for the massive set of agent runtime, model, and environment combinations?

**ageval** (agent eval) switches the agent under test with plugins on one running base: write a dataset once, and swap Agent or environment in config. With the CLI and skills installed, your coding agent can design, convert, and run benchmarks end to end; results upload to the Hub together with datasets, plugins, and agent configs, ready to share or reuse.

- **Swap the agent under test fast** — environments and agent runtimes join as plugins ([ACP](https://agentclientprotocol.com) by default; nooa / dsh / miniswe take the same plugin path), no base changes; one line in `profiles.yaml`, or `--agent` for a single run.
- **Let the Agent run the eval** — skills teach your coding agent the CLI and dataset authoring; from there it designs or converts a benchmark and runs the eval itself.
- **Share and reuse on the Hub** — public datasets, plugins, and agent configs are there to reuse: `ageval run <org>/<name>@<version>`.

The CLI is `ageval` (PyPI package `ageval-cli`).
