How do you avoid rewriting scaffolds for every combination of agent runtime, model, and environment?

**ageval** (agent eval) evaluates coding agents. Write a dataset once. Swap the environment and the Agent in config.

Install the CLI and skills, and your coding agent can design, convert, and run a benchmark. Results upload to the Hub together with datasets, plugins, and agent configs, so others can run them too.

- **Swap the agent under test.** Environments and agent runtimes join as plugins ([ACP](https://agentclientprotocol.com) by default; nooa / dsh / miniswe take the same plugin path). One line in `profiles.yaml`, or `--agent` for this run.
- **Let the Agent run the eval.** Skills teach your coding agent the CLI and dataset authoring. From there it designs or converts a benchmark and runs it.
- **Share and reuse on the Hub.** Public datasets, plugins, and agent configs: `ageval run <org>/<name>@<version>`.

The CLI is `ageval` (PyPI package `ageval-cli`).
