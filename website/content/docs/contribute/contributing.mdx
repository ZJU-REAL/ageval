title: Contributing guide
description: Track work with Issues; design changes start in docs.
---

```text
docs/design     → mechanism (self-contained; no external BRIEF)
ARCHITECTURE.md → structure
GitHub Issues   → work and acceptance
code / tests    → behavior
website/        → how-to
```

1. Open or claim an [Issue](https://github.com/ZJU-REAL/ageval/issues)
2. Mechanism → `docs/design/`; layout → `ARCHITECTURE.md`
3. Implement, test, link the Issue
4. Update this site when user-visible behavior changes

Don’t rebuild Spec checkbox machines; don’t put secrets in yaml/evidence; don’t treat trajectory as PASS; don’t name adapters after benchmarks.

Full routing: [`AGENTS.md`](https://github.com/ZJU-REAL/ageval/blob/main/AGENTS.md).
