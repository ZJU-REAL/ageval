---
title: 导出证据
description: 打包并导出单次运行的归档证据。
---

单次运行的证据归档默认位于 `.ageval/runs/<id>/`。轨迹封存完成后，默认归档目录保留 `lock.json`、`result.json`、`trajectory.jsonl`、`summary.json` 与 `task-artifacts/**`（以及存在时的 `verifier-collect/**`、`evaluation/observation.jsonl` 与 `evaluation/checks.json`）。传入 `--keep-vendor-raw`（默认关闭）会额外保留单次调用的 `backend_raw/` 原始响应、中间调用事件文件与 `evaluator_raw.json`。`--keep-workspace` 仅保留宿主工作区临时目录，与 `--keep-vendor-raw` 相互独立。

```bash
ageval evidence --help
ageval run <dataset> --task <id> --keep-vendor-raw
```

导出内容自动经过脱敏检查，不携带明文密钥。本地结果可通过 `ageval view` 查看。
