---
title: 导出证据
description: 打包并导出单次运行的归档证据。
---

单次运行的证据归档默认位于 `.ageval/runs/<id>/`。尚未同时写出 `result.json` 和 `trajectory.jsonl` 的 Attempt 会保留 `activity.jsonl` 和 `checkpoints/`，供 `--resume` 继续。两份文件都写出之后，除非指定 `--keep-recovery-state`（或未指定该开关且 `AGEVAL_KEEP_RECOVERY_STATE` 为真），这两份恢复文件会被删掉。留下的恢复文件还包括 `replay-input.json`。`ageval checkpoints`、`ageval run --fork` 和 `ageval replay` 读的就是这份恢复文件。回放子 Attempt 会把任务原文、在新环境里重新执行的每条动作，以及这次执行的观察，写入 `trajectory.jsonl`。`--keep-workspace` 不保留它们。轨迹封存完成后，默认归档目录保留 `lock.json`、`result.json`、`trajectory.jsonl`、`summary.json` 与 `task-artifacts/**`（以及存在时的 `verifier-collect/**`、`evaluation/observation.jsonl` 与 `evaluation/checks.json`）。传入 `--keep-vendor-raw`（默认关闭）会额外保留单次调用的 `backend_raw/` 原始响应、中间调用事件文件与 `evaluator_raw.json`。`--keep-workspace` 仅保留宿主工作区目录，与 `--keep-vendor-raw`、`--keep-recovery-state` 相互独立。

```bash
ageval evidence --help
ageval run <dataset> --task <id> --keep-vendor-raw
```

导出内容自动经过脱敏检查，不携带明文密钥。本地结果可通过 `ageval view` 查看。
