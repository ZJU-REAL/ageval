---
title: Export evidence
description: Pack the files from one run to take elsewhere.
---

Evidence archives live under `.ageval/runs/<id>/`. After trajectory sealing completes, the default archived directory retains `lock.json`, `result.json`, `trajectory.jsonl`, `summary.json`, and `task-artifacts/**` (plus `verifier-collect/**`, `evaluation/observation.jsonl`, and `evaluation/checks.json` when present). Passing `--keep-vendor-raw` (off by default) additionally retains per-invocation `backend_raw/` dumps, intermediate invocation event files, and `evaluator_raw.json`. `--keep-workspace` preserves the host workspace directory only and is independent of `--keep-vendor-raw`.

```bash
ageval evidence --help
ageval run <dataset> --task <id> --keep-vendor-raw
```

Exports are checked for secret redaction. Open local results with `ageval view`.
