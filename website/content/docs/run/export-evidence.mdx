---
title: Export evidence
description: Pack the files from one run to take elsewhere.
---

Evidence archives live under `.ageval/runs/<id>/`. An Attempt that has not written both `result.json` and `trajectory.jsonl` keeps `activity.jsonl` and `checkpoints/` so `--resume` can continue it. After both files exist, that recovery bundle is removed unless `--keep-recovery-state` is set (or `AGEVAL_KEEP_RECOVERY_STATE` is true and the flag is omitted). The retained bundle is what `ageval checkpoints` and `ageval run --fork` read. `--keep-workspace` does not keep the bundle. After trajectory sealing completes, the default archived directory retains `lock.json`, `result.json`, `trajectory.jsonl`, `summary.json`, and `task-artifacts/**` (plus `verifier-collect/**`, `evaluation/observation.jsonl`, and `evaluation/checks.json` when present). Passing `--keep-vendor-raw` (off by default) additionally retains per-invocation `backend_raw/` dumps, intermediate invocation event files, and `evaluator_raw.json`. `--keep-workspace` preserves the host workspace directory only and is independent of `--keep-vendor-raw` and `--keep-recovery-state`.

```bash
ageval evidence --help
ageval run <dataset> --task <id> --keep-vendor-raw
```

Exports are checked for secret redaction. Open local results with `ageval view`.
