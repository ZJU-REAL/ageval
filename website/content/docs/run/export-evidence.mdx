Materials already live under `.ageval/runs/<id>/`. After a successful write the durable tree is `lock.json` / `result.json` / `trajectory.jsonl` / `summary.json` / `task-artifacts/**`. `--keep-vendor-raw` (off by default) keeps invoke `backend_raw/`, layer B, and `evaluator_raw.json`. `--keep-workspace` is the host work root only; it does not keep vendor raw.

```bash
ageval evidence --help
ageval run <dataset> --task <id> --keep-vendor-raw
```
