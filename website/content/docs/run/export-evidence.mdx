---
title: Export evidence
description: Pack the files from one run to take elsewhere.
---

Evidence archives live under `.ageval/runs/<id>/`. An Attempt that has not written `result.json` also keeps `activity.jsonl` and `checkpoints/` so `--resume` can continue it. After `result.json` and `trajectory.jsonl` both exist, `checkpoints/` is removed unless `--keep-workspace` is set. `activity.jsonl` stays. After trajectory sealing completes, the default archived directory retains `lock.json`, `result.json`, `trajectory.jsonl`, `summary.json`, and `task-artifacts/**` (plus `verifier-collect/**`, `evaluation/observation.jsonl`, and `evaluation/checks.json` when present). Passing `--keep-vendor-raw` (off by default) additionally retains per-invocation `backend_raw/` dumps, intermediate invocation event files, and `evaluator_raw.json`. `--keep-workspace` preserves the host workspace directory only and is independent of `--keep-vendor-raw`.

```bash
ageval evidence --help
ageval run <dataset> --task <id> --keep-vendor-raw
```

Exports are checked for secret redaction. Open local results with `ageval view`.
