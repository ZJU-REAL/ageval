---
title: Campaign parameter matrix
description: Sweep allowlisted fields on one task.
---

Campaign means: **one task**, many allowlisted parameter points, each with its own Result.

```bash
ageval campaign <dataset> --task <id> ...
```

See `ageval campaign --help` for matrix flags.

| | Suite | Campaign | Always-k (`-k`) |
| --- | --- | --- | --- |
| Axis | Many tasks | Parameter combos on one task | Repeated independent Attempts |
| Typical use | Full-suite regression | Compare seed / profile / binding | Samples for pass@k / pass^k |
| Entry | `ageval run` (optional `--task`) | `ageval campaign` | `ageval run … -k N` |

**Matrix axis ≠ k-attempt axis.** Always-k is not a campaign matrix field and is not in `task.yaml`.

Overrides still follow the `--set` allowlist.
