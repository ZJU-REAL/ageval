---
title: Switch agent and model
description: Swap coding-agent entries with profiles, --agent, --model, or --set.
---

One task can declare several `agent_profiles` and pick which to use at run time.

## What’s on this host?

```bash
ageval executors -v
```

Check `engine_ready` / `acp_entry_ready` per ACP entry.

## Declare in config

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: docker
agent_profiles:
  solver:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: pi
    model: gpt-5.4-mini
```

ACP `entry` lives on `- plugin: acp` / `options.entry`.

## Agent packages (`--agent`)

`ageval.agent/1` is an Agent package (executor, entry, overlays); `binding.model` is the default, not identity.

| Goal | How |
| --- | --- |
| Built-in package | `--agent pi`. Built-ins `pi` / `opencode` / `codex` / `claude-code` / `grok-build` / `openai-http` / `anthropic-http` ship with ageval — no install |
| Custom overlay pack | `ageval agent install org/name@0.1.0` first, then bind. Install also pulls `binding.extensions[].plugin` (skips contrib; a missing plugin or unsatisfied `host_requires` rejects the whole install) |
| Model for this run only | `--model <name>` (with `--agent`; omit to keep the package default. Not `ageval results upload-suite --model` — that is an observational upload label) |

`--agent` and `--profiles` are mutually exclusive.

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg --agent pi --model glm-4.7
ageval agent install examples/agents/pi-default
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg --agent local/pi-default@0.1.0
```

## Temporary switch

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg \
  --set '/bindings/solver/options/entry="codex"'
```

Only allowlisted `--set` pointers work, e.g. `/bindings/solver/options/reasoning_effort="high"` — [CLI](../reference/cli.mdx).

`api_key` is always an env **name**, never the secret. Optional profile fields: `options.reasoning_effort` (thinking level), `options.idle_timeout_seconds` (stall ceiling), and `base_url`.

Non-ACP agent runtimes (nooa / dsh / miniswe) switch with a whole `--profiles` file. They ship as plugins: `ageval plugin install plugins/<name>`, then set `executor:` to that name and attach the matching `plugin:` line in profiles.
