---
title: 运行单个 Task
description: 指定 --task，读 Result 和 logs。
---

## 命令

```bash
ageval run <dataset> --task <task_id>
```

例子：

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg

# Always-k：同一 task 固定 k 次独立运行（CLI only；默认 k=1）
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg -k 5
```

只检查配置、不跑 agent：

```bash
ageval lock examples/datasets/minimal-demo --task terminal-jsonl-agg
```

`--task` 必须等于成员目录名和 `task.yaml` 里的 `task_id`。  
TTY 下 stdout 是短 recap（单题含 `logs` 路径）；管道或 `--json` 仍是完整文档。`k>1` 走整份 dataset 的 job，写 `.ageval/suite-runs/`。

## 断点恢复

```bash
ageval run <dataset> --task <task_id> --resume <attempt_id>
```

父进程在写出 `result.json` 之前停掉时，用这条命令继续同一次 Attempt。ageval 保留原来的 Attempt id。已经完成的步骤留在 `.ageval/runs/<attempt_id>/activity.jsonl`。仍与最后完成步骤对齐的环境会被原地接回。环境已经丢失时，会重新启动，并从最近的检查点恢复 `/attempt/workspace` 和 `/attempt/home`。已经完成的调用不会再执行。已经消耗的墙钟时间和调用次数仍然计入限额。

`result.json` 已经存在、锁定配置摘要对不上、或环境还在跑这次 Attempt 时，命令以 exit 2 结束，不写 `result.json`。

<Callout type="info" title="整份 dataset 跑一遍">

不加 `--task` 就会整份跑，所有成员进同一个 job。`ageval status <suite_run_id> --dataset <dataset>` 看 progress，`ageval cancel <suite_run_id> --dataset <dataset>` 叫停。

</Callout>

## 跑完你会看到什么

- 终端里的 **Result 摘要**（状态、分数相关字段、错误信息）  
- **`logs` 路径**：Dataset 根下 `.ageval/runs/<run_id>/`（`k=1`）  
- `k>1` 时：`summary.json` 里的 **pass@k / pass^k** 等 job 指标  

PASS / FAIL 只来自 `evaluator.py`。低分是 FAIL。run 用尽 `wall_time_seconds` 或 `agent_invocations` 时，evaluator 照常打分，`result.json` 的 `limit` 记下对应的配额键名。environment 或 evaluate 时钟到期记 ERROR。evaluator 的 status 只许 PASS 或 FAIL，其它返回值也记 ERROR。

## 常见失败

| 现象 | 先查 |
| --- | --- |
| lock 失败 | 配置 / `task_id` / 目录约定 |
| agent 起不来 | `ageval executors -v`、凭据 |
| 评测 FAIL | artifacts 是否写出、evaluator 输入 |
