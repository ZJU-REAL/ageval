---
title: Run a single task
description: Use --task, read the Result and logs path.
---

## Command

```bash
ageval run <dataset> --task <task_id>
```

Example:

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg

# Always-k: fixed k independent Attempts for one task (CLI only; default k=1)
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg -k 5
```

Config only, no agent:

```bash
ageval lock examples/datasets/minimal-demo --task terminal-jsonl-agg
```

`--task` must match the member directory name and `task_id` in `task.yaml`.  
On a TTY, stdout is a short recap (single task: `logs` path). A pipe or `--json` still writes the JSON document. With `k>1`, the run is a suite job under `.ageval/suite-runs/`.

<Callout type="info" title="The whole dataset">

Omit `--task` to run every member in one job. `ageval status <suite_run_id> --dataset <dataset>` shows progress; `ageval cancel <suite_run_id> --dataset <dataset>` stops it.

</Callout>

## What you get

- A **Result** summary on the terminal  
- A **`logs` path** under the Dataset root: `.ageval/runs/<run_id>/` (when `k=1`)  
- For `k>1`: job metrics such as **pass@k / pass^k** in suite `summary.json`  

PASS / FAIL comes only from `evaluator.py`, not from the Agent finishing. A low score or a timeout is FAIL (score 0); a dead environment or a crashed evaluator is ERROR.

## Common failures

| Symptom | Check |
| --- | --- |
| Lock fails | Config / ids / layout |
| Agent won’t start | `ageval executors -v`, credentials |
| Eval FAIL | Artifacts / evaluator inputs |
