---
title: Provenance
description: Optional upstream declaration.
---

```yaml
provenance:
  kind: port
  upstream:
    name: some-bench
    url: https://github.com/…
    ref: v0.1.0
```

Root dataset default and/or member override (member **replaces** root).  
`port`-like kinds need `upstream.url` plus `ref` or `commit`.
