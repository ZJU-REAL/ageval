`run.py` owns the loop, roles, local tools, and published artifacts.

| You own | Do not |
| --- | --- |
| loop, roles, tools | PASS, host credentials, isolation |
| SDK `session` / `invoke` | A vendor SDK as Core |

Scoring lives in `evaluator.py`: a deterministic script against gold, or an optional LLM-as-judge after gold lands.

<Callout type="idea" title="Have an agent write it">

```bash
npx skills add ZJU-REAL/ageval --skill ageval-sdk-harness
```

Describe the loop you need and let your coding agent produce `run.py`; the snippet below is what it must satisfy.

</Callout>

```python
from ageval_sdk import RunContext, RunTerminal

async def run(ctx: RunContext) -> RunTerminal:
    async with ctx.agent.session("solver", max_turns=1) as session:
        reply = await session.invoke(ctx.params["instruction"])
    ctx.publish_json("reply", {"ok": bool(reply.get("ok")), "text": reply.get("text") or ""})
    if not reply.get("ok"):
        return RunTerminal.failed(str(reply.get("error") or "invoke_failed"))
    return RunTerminal.completed("ok")
```

`session.invoke` may take `tools` and `messages`. `openai-http` /
`anthropic-http` return structured `tool_calls`; ACP ignores the catalog
and stays on text invoke. Omit both for prompt-only.

For `openai-http`, set `options.stream: true` in the profile to consume native
SSE for Chat Completions and Responses. The task still receives the same
`invoke` result; streaming changes transport and progress evidence, not the
task contract or PASS. A failed or incomplete stream is an `ok: false` result.
Live activity holds unfinished tokens and credential prefixes until they can be
redacted safely, then publishes safe text without waiting for the whole response.

Files present are recognized. Do not declare a harness entrypoint.

For native Anthropic Messages SSE, set `options.stream: true` in the role profile
(default `false`). Optional `stream_first_event_timeout_seconds` and
`stream_idle_timeout_seconds` report first-event/idle failures without extending
invocation or task limits; pings are not answer progress. Partial output is visible
in activity and is not a completed response. Set `omit_temperature: true` only
when the provider requires its default temperature. SDK task code and evaluator
ownership are unchanged.
Tool-use activity snapshots retain redacted partial arguments even when a stream
is cancelled or malformed. The idle limit starts at response headers, including
the interval before the first SSE data event.
