Goal: lock, run, and get an evaluation result on this machine.

<Callout type="info" title="Prerequisites">

Tutorial commands use in-repo `examples/…` paths, so clone the repo first. The CLI itself installs with `uv tool install ageval-cli`; `uv sync` is only for changing ageval itself.

</Callout>

<Callout type="idea" title="Have an agent write it">

```bash
npx skills add ZJU-REAL/ageval --skill ageval-config-package
npx skills add ZJU-REAL/ageval --skill ageval-sdk-harness
```

Describe the task you want and your coding agent produces the directory, `task.yaml`, `run.py`, and `evaluator.py`. Copying the steps below by hand works just as well.

</Callout>

Copy a `tasks/<id>/` directory from [`examples/datasets/minimal-demo`](https://github.com/ZJU-REAL/ageval/tree/main/examples/datasets/minimal-demo) (start from `terminal-jsonl-agg`). The directory name must equal `task_id`.

```yaml
format: ageval.task/1
task_id: hello
parameters:
  instruction: "Reply DONE"
agent_profiles:
  - id: solver
limits:
  wall_time_seconds: 300
  agent_invocations: 1
artifacts:
  publishable:
    - id: reply
      path: artifacts/reply.json
evaluation:
  inputs:
    - artifact: reply
      target: artifacts/reply.json
```

Do not write `harness:`, `provider:`, or `assurance`. The environment and ACP entry live in `profiles.yaml`.

```bash
ageval lock examples/datasets/minimal-demo --task hello
ageval run  examples/datasets/minimal-demo --task hello
```

Scoring defaults to a script against gold. For LLM-as-judge, add a role on the same `profiles.yaml` and `Agent.session` after gold lands. For several scoring images with different closures scored in sequence, declare `evaluation.environments` on the task; the evaluator names the host for each stage.
