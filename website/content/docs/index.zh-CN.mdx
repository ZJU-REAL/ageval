怎么避免为 Agent 运行时、模型和环境的各种组合，一遍遍重写脚手架？

**ageval**（agent eval）评测的是 coding agent。一份 dataset 写一次，换环境和 Agent 只改配置。

装上 CLI 和 skill，你的 coding agent 可以设计、转化 benchmark，并自己跑完评测。结果、dataset、插件和 Agent 配置都能上传 Hub，给别人接着用。

- **切换待评测 Agent.** 环境和 Agent 运行时都经插件接入（默认 [ACP](https://agentclientprotocol.com)，nooa / dsh / miniswe 同一条插件路）。`profiles.yaml` 改一行，或这次运行用 `--agent`。
- **让 Agent 自己跑评测.** skill 教会你的 coding agent 用 CLI、写 dataset；之后由它设计或转化 benchmark，自动跑完。
- **在 Hub 上分享与复用.** 公开的 dataset、插件和 Agent 配置都能复用：`ageval run <org>/<name>@<version>`。

CLI 命令是 `ageval`（PyPI 包 `ageval-cli`）。
