以本机 `uv run ageval --help` 为准。

```bash
uv run ageval tasks <dataset>
uv run ageval lock <dataset> --task <id>
uv run ageval lock <dataset> --task <id> --probe
uv run ageval run <dataset> --task <id>
uv run ageval run <dataset> --task <id> --probe
uv run ageval run <dataset>                         # suite
uv run ageval run <dataset> --max-concurrent-tasks 2
uv run ageval run <dataset> -k 5                    # Always-k（每题 k 次）
uv run ageval run <dataset> --resume-suite <suite_run_id> --task <id> -k 5
uv run ageval campaign <dataset> --task <id> ...
uv run ageval status <suite_run_id> --dataset <dataset>
uv run ageval cancel <suite_run_id> --dataset <dataset>
uv run ageval executors -v
uv run ageval plugin install <path|ref>
uv run ageval plugin list
uv run ageval plugin uninstall <plugin_id>
uv run ageval agent install <path|ref>
uv run ageval agent list
uv run ageval agent uninstall <agent_id>
uv run ageval evidence --help
uv run ageval view <dataset> [--dev] [--open /jobs/<id>]
uv run ageval jobs delete --local <dataset> --job <id> --yes
# Registry / 结果（需 login；细节见 [Registry](/docs/share/registry)）
uv run ageval publish <dataset> --org <org> [--draft] [--public] [--replace]
uv run ageval release <dataset_id> [--public] [--replace]
uv run ageval registry list|show|set-visibility|delete|org-create|org-list|org-add-member|org-set-role|org-transfer|org-remove-member …
uv run ageval results upload|upload-suite|attach-agent|request|inbox|decide|share|unshare|set-visibility|delete …
```

路径 = dataset 根（含 `ageval.yaml`）。`--agent` 与 `--profiles` 互斥。删除类命令须显式 `--yes`；同 identity 覆盖须显式 `--replace`（默认 409）。

## `ageval run` 常用选项

| 选项 | 含义 |
| --- | --- |
| `--task <id>` | 只跑该成员；省略 = 整包 suite |
| `--max-concurrent-tasks N` | 并行 unit 上限；**只加速**，不改 k / PASS |
| `--n-attempts` / `-k N` | Always-k：每题 N 次独立 Attempt（默认 1）；**CLI/job only** |
| `--resume-suite <suite_run_id>` | 并进已有 job：跳过已完成 unit，追加 Attempt，重算 pass@k / pass^k |
| `--replace-slot` | 配合 `--resume-suite --task`：重跑该已完成槽；新 Attempt；旧行进 `previous[]` |
| `--attempt-index N` | Always-k 要换的格（默认 0）。只与 `--replace-slot` 一起用 |
| `--keep-workspace` | 清理后保留环境工作根（默认删除）。 |
| `--agent` | 用已安装的 `ageval.agent/1` 绑定 job；与 `--profiles` 互斥 |
| `--set` / `--profiles` | 见下；与 job binding 相关 |
| `--probe` | 只做可行性：按绑定 / `environment` 打印 plan + readiness。不 invoke Agent、不 bake、不改 lock digest。选中路径不满足则 exit 1。 |

## `status` / `cancel`

| 命令 | 含义 |
| --- | --- |
| `ageval status <run_id\|suite_run_id>` | ControlStore；suite 可加 `--dataset` 读 `progress.json` |
| `ageval cancel <run_id\|suite_…>` | 单 Run 或 suite job；suite 可加 `--dataset` 写 `cancel.requested` |

## `--set`

格式：`<JSON Pointer>=<JSON 值>`，可重复。

| 指针 | 含义 |
| --- | --- |
| `/parameters/seed` | 业务 seed 等 |
| `/parameters/active_profile` | 切换 profile |
| `/bindings/<role>/options/<key>` | job binding 覆盖（含 `entry`、插件 `agent` 等；ACP 仍拒绝 `command` / engine 键） |
| `/limits/wall_time_seconds` | 墙钟（intent；**不可**覆盖 — 见下） |

Intent `limits.*` **不能**经 `--set` 覆盖。其它指针在 lock 阶段失败。
