Trust `uv run ageval --help`.

```bash
uv run ageval tasks <dataset>
uv run ageval lock <dataset> --task <id>
uv run ageval lock <dataset> --task <id> --probe
uv run ageval run <dataset> --task <id>
uv run ageval run <dataset> --task <id> --probe
uv run ageval run <dataset>
uv run ageval run <dataset> --max-concurrent-tasks 2
uv run ageval run <dataset> -k 5
uv run ageval run <dataset> --resume-suite <suite_run_id> --task <id> -k 5
uv run ageval campaign <dataset> --task <id> ...
uv run ageval status <suite_run_id> --dataset <dataset>
uv run ageval cancel <suite_run_id> --dataset <dataset>
uv run ageval executors -v
uv run ageval plugin install <path|ref>
uv run ageval plugin list
uv run ageval plugin uninstall <plugin_id>
uv run ageval agent install <path|ref>
uv run ageval agent list
uv run ageval agent uninstall <agent_id>
uv run ageval evidence --help
uv run ageval view <dataset> [--dev] [--open /jobs/<id>]
uv run ageval jobs delete --local <dataset> --job <id> --yes
# Registry / results (login required; see [Registry](/docs/share/registry))
uv run ageval publish <dataset> --org <org> [--draft] [--public] [--replace]
uv run ageval release <dataset_id> [--public] [--replace]
uv run ageval registry list|show|set-visibility|delete|org-create|org-list|org-add-member|org-set-role|org-transfer|org-remove-member …
uv run ageval results upload|upload-suite|attach-agent|request|inbox|decide|share|unshare|set-visibility|delete …
```

Path = dataset root. `--agent` and `--profiles` are mutually exclusive. Destructive commands require `--yes`; overwrite same identity requires `--replace` (default 409).

## Common `ageval run` flags

| Flag | Meaning |
| --- | --- |
| `--task <id>` | One member; omit = full suite |
| `--max-concurrent-tasks N` | Max concurrent units; **speeds wall time only** |
| `--n-attempts` / `-k N` | Always-k: N independent Attempts per task (default 1); **CLI/job only** |
| `--resume-suite <suite_run_id>` | Resume job: skip finished units, append Attempts, recompute pass@k / pass^k |
| `--replace-slot` | With `--resume-suite --task`: re-run that finished slot; new Attempt; old row stays in `previous[]` |
| `--attempt-index N` | Always-k slot to replace (default 0). Only with `--replace-slot` |
| `--keep-workspace` | Keep the environment work root after cleanup (default: delete). Uploads never pack it. Docker volumes are still removed |
| `--agent` | Bind an installed `ageval.agent/1` package; mutually exclusive with `--profiles` |
| `--set` / `--profiles` | Overrides / alternate job binding |
| `--probe` | Feasibility only: plan + readiness for this binding/`environment`. No Agent, no bake, no lock digest change. Exit 1 if the selected path is unsatisfied. |

## `status` / `cancel`

| Command | Meaning |
| --- | --- |
| `ageval status <run_id\|suite_run_id>` | ControlStore; add `--dataset` for suite `progress.json` (system suite id defaults to 8 hex) |
| `ageval cancel <run_id\|suite_…>` | One Run or suite job; suite may use `--dataset` → `cancel.requested` |

## `--set`

| Pointer | Meaning |
| --- | --- |
| `/parameters/seed` | Seed etc. |
| `/parameters/active_profile` | Profile id |
| `/bindings/<role>/options/<key>` | Job binding override (`entry`, plugin `agent`, …; ACP still rejects `command` / engine keys) |
| Intent `limits.*` | **Not** overridable via `--set` |

Anything else fails at lock. Details: `src/ageval/cli/README.md` · skill `ageval-cli`.
