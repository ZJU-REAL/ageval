## 安装

```bash
uv tool install ageval-cli
ageval -V
```

- CPython **3.12+**（`uv` 会自行准备解释器）
- 真实 coding agent 路径需要本机 ACP 入口与凭据。仅 `ageval lock` 不需要。
- 升级：`uv tool upgrade ageval-cli`

CLI 装好即可用：dataset 用 registry ref（`<dataset_id>@<version>`）从 Hub 获取，或指向任意本地 dataset 根目录。默认连公开 Hub，不必先设 `AGEVAL_REGISTRY_URL`；自托管或 compose 再用该变量 / `--registry-url` 覆盖。

## 可选 extras

可选后端以 extras 提供，按需安装；同一命令重跑即升级（uv 有缓存，开销很小）：

```bash
uv tool install 'ageval-cli[all]'   # 一次装全
```

| Extra | 用途 |
| --- | --- |
| `e2b` | [e2b](https://e2b.dev) 云沙箱环境 |
| `daytona` | [Daytona](https://www.daytona.io) 沙箱环境 |
| `registry` | 自托管 Registry / Hub 服务 |
| `nooa` / `dsh` / `miniswe` | 对应外部 harness 插件 |

缺 extras 或凭据时 lock/run 检查不过就不能进入运行，报错信息带准确的安装命令。

## 从源码开发（贡献者）

修改 ageval 本体或运行仓库内示例时才需要 clone：

```bash
git clone https://github.com/ZJU-REAL/ageval.git
cd ageval
uv sync --frozen --all-packages
uv run ageval -V
```

## Skills

给本机 coding agent 安装仓库技能：

```bash
npx skills add ZJU-REAL/ageval                      # 全部技能
npx skills add ZJU-REAL/ageval --skill ageval-cli   # 单个技能
```

| Skill | 用途 |
| --- | --- |
| `ageval-platform` | 边界与文档路由 |
| `ageval-cli` | CLI |
| `ageval-plugin` | `ageval.plugin/1` |
| `ageval-config-package` | dataset / task |
| `ageval-sdk-harness` | `run.py` / SDK |
