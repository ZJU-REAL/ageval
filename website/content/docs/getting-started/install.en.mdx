## Install

```bash
uv tool install ageval-cli
ageval -V
```

- CPython **3.12+** (`uv` prepares the interpreter itself)
- A real coding-agent path needs a host ACP entry and credentials. `ageval lock` does not.
- Upgrade: `uv tool upgrade ageval-cli`

Once installed, datasets come from the Hub by registry ref (`<dataset_id>@<version>`), or point at any local dataset root. The CLI defaults to the public Hub — you do not need `AGEVAL_REGISTRY_URL` first. Override it (or `--registry-url`) for self-host / compose.

## Optional extras

Optional backends ship as extras. Install on demand; rerunning the same command upgrades in place (uv caches, so this is cheap):

```bash
uv tool install 'ageval-cli[all]'   # everything at once
```

| Extra | For |
| --- | --- |
| `e2b` | [e2b](https://e2b.dev) cloud sandbox environment |
| `daytona` | [Daytona](https://www.daytona.io) sandbox environment |
| `registry` | Self-hosted Registry / Hub service |
| `nooa` / `dsh` / `miniswe` | The matching external harness plugins |

Missing extras or credentials fail the check at lock/run and the run does not start; the error includes the exact install command.

## Develop from source (contributors)

Clone only when changing ageval itself or running the in-repo examples:

```bash
git clone https://github.com/ZJU-REAL/ageval.git
cd ageval
uv sync --frozen --all-packages
uv run ageval -V
```

## Skills

Install the repo skills into your local coding agent:

```bash
npx skills add ZJU-REAL/ageval                      # all skills
npx skills add ZJU-REAL/ageval --skill ageval-cli   # one skill
```

| Skill | Use |
| --- | --- |
| `ageval-platform` | Boundaries and doc routing |
| `ageval-cli` | CLI |
| `ageval-plugin` | `ageval.plugin/1` |
| `ageval-config-package` | dataset / task |
| `ageval-sdk-harness` | `run.py` / SDK |
